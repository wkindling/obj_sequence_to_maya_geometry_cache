# obj_sequence_to_maya_geometry_cache
Input obj sequence, dump the corresponding Maya geometry (written by Claude).

Usage:
usage: obj_to_maya_cache.py [-h] -o OUT [--channel CHANNEL] [--fps FPS] [--start-frame START_FRAME] [--include-initial] [--double] [--per-frame]
                            initial_obj anim_pattern
obj_to_maya_cache.py: error: the following arguments are required: initial_obj, anim_pattern, -o/--out
